## Selected projects

### 🧬 [iORF recurrence framework](https://github.com/Mishuda/iORF-recurrence-framework)

Reproducible analysis framework for investigating the recurrence of pervasive translation across **54 yeast Ribo-seq datasets**.

The project identifies a stringent set of candidate intergenic ORFs and evaluates their support across individual datasets using read-frame information and an empirical low-signal reference population.

**Highlights**
- Analysis of a 78,989-iORF search space
- 886 stringent pooled candidate iORFs
- Dataset-specific recurrence and empirical support analysis
- Quality-control and sensitivity analyses
- Genomic-context and recurrence-stratification analyses
- Reproducible R environment and documented analysis dependencies

`R` `Ribo-seq` `Statistics` `Data visualization` `Reproducible research`

---

### 🔬 [Heatmapper Scripts](https://github.com/Mishuda/heatmapper-scripts)

Python utilities for processing **KOfamScan** outputs and visualizing metabolic pathway completeness.

The project includes preprocessing of functional annotation results and configurable generation of comparative pathway-completeness heatmaps.

`Python` `Pandas` `Matplotlib` `KEGG` `KOfamScan` `Metabolic reconstruction`

---

### 🧮 [Max-Cut via Tabu Search](https://github.com/Mishuda/metaheu_max_cut)

Implementation and experimental evaluation of **Tabu Search** for the weighted Max-Cut combinatorial optimization problem.

Includes incremental objective updates, random-search and greedy baselines, reproducible instance generation, and systematic evaluation across graph sizes and algorithm parameters.

`Python` `Algorithms` `Optimization` `Metaheuristics`
